# E-Commerce Marketing OS — Phase A

Early implementation, **not production-ready**. Implemented: public landing page with illustrated social-media concept (integrations are not yet available), workspace registration, password login, database-backed sessions, tenant-scoped draft creation/listing/editing/deletion, editorial planning dates and categories with month/week calendar views, a role-aware idea → draft → review → approved workflow with transition history, a tenant-scoped CSV export of dated content, a dashboard comparing exact counts of dated editorial content by status for two equal-length periods, a manual competitor radar with source links, observation dates and collection timestamps, and a token encryption primitive. Planning dates are indicative only and do not trigger publication. Competitor information is user-entered and not automatically verified; there is no scraping or automated competitor analysis. The social, advertising, AI, automation, scheduling worker, PDF and external analytics reports, billing, password recovery, email verification, admin, and team-management features are not implemented. No external data is simulated. Do not deploy with real customer data yet: production hardening, infrastructure, email verification, comprehensive abuse controls, backups, monitoring, and a security review remain necessary.

## Requirements

Node.js 24 and a PostgreSQL database. Copy `.env.example` to `.env.local` and set `DATABASE_URL` (keep credentials out of source control). Apply migrations with `DATABASE_URL=... npm run migrate` (also run this after updating an existing installation), then start with `npm run dev`. Visit `http://localhost:3000`. Run `npm test` for unit and database integration tests; these use an isolated PGlite PostgreSQL engine, not a live production database. `npm run build` checks the application build. For browser integration tests, install a Playwright Chromium browser with `npx playwright install chromium`, then run `npm run test:e2e`; alternatively set `CHROMIUM_PATH` to an installed Chromium executable. The test creates a temporary in-memory database and starts a local app server.
